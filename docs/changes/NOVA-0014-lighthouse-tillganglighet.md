# Tillgängligare kontaktlänk

## Vad ändrades?

Kontaktadressen på startsidan har fått tydlig länkmarkering med understrykning.

## Varför?

Lighthouse kunde inte skilja kontaktlänken tillräckligt tydligt från den omgivande brödtexten.

## Resultat

Kontaktlänken är nu tydligt identifierbar även utan att förlita sig på färgskillnad.

## Dokumentationspåverkan

Ingen.
