# Alt-text för Nova IT-loggor

## Vad ändrades?

Nova IT-loggorna i huvudnavigering, sidfot och juridiska dialoger fick
beskrivande alt-text.

## Varför?

Bing Webmaster Tools flaggade loggbilderna som saknade bildalternativ vid
URL-inspektion av publika sidor. Ändringen gör företagsmärket tydligare för
sökmotorer och hjälpmedel.

## Resultat

Loggbilderna använder nu `alt="Nova IT"` i stället för tom alt-text.

Ingen.
